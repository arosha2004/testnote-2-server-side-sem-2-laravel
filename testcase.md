# NoteHub API Postman Test Cases Reference

This table documents the 5 specific API test cases executed via Postman, matching the credentials, payloads, and response structures from the test runs.

| Test Case ID | Test Scenario | Test Steps | Prerequisites | Test Data | Expected/Intended Results | Actual Results | Test Status – Pass/Fail |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :---: |
| **TC-001** | API User Registration | Send `POST` request to `http://127.0.0.1:8000/api/register` with new user details | Database connection active; Email not registered | **JSON Body:**<br>`{ "name": "John Doe", "email": "john@gmail.com", "password": "password", "password_confirmation": "password" }` | HTTP status code `201 Created` with a JSON payload returning the generated `access_token`, `token_type: Bearer`, and `user` object details | Returned `201 Created` with access token and user profile object | **Pass** |
| **TC-002** | API User Login | Send `POST` request to `http://127.0.0.1:8000/api/login` with credentials | Registered user exists in database | **JSON Body:**<br>`{ "email": "john@gmail.com", "password": "password" }` | HTTP status code `200 OK` returning a new stateful `access_token`, `token_type: Bearer`, and the `user` object | Returned `200 OK` with active access token and authenticated user data | **Pass** |
| **TC-003** | API Display Notes | Send `GET` request to `http://127.0.0.1:8000/api/notes` with Authorization Header | User is registered and logged in; Valid token exists | **Headers:**<br>`Authorization: Bearer <token>` | HTTP status code `200 OK` returning a paginated JSON response with `current_page`, `data` array of note items, and pagination URLs | Returned `200 OK` listing the owned note ("Meeting Notes") within the paginated JSON data | **Pass** |
| **TC-004** | API Input Validation | Send `POST` request to `http://127.0.0.1:8000/api/notes` with missing title field | Valid Sanctum Bearer token passed in header | **JSON Body:**<br>`{}` (Empty payload) | HTTP status code `422 Unprocessable Content` returning JSON errors: `"The title field is required."` | Returned `422 Unprocessable Content` with validation error messages in JSON structure | **Pass** |
| **TC-005** | API SQL Injection Protection | Send `POST` request to `http://127.0.0.1:8000/api/notes` containing SQL injection characters | Valid Sanctum Bearer token passed in header | **JSON Body:**<br>`{ "title": "SQL Test Note", "content": "'; DROP TABLE notes; --" }` | SQL injection characters are securely escaped via Eloquent parameterized bindings, treating the payload as literal note text | The payload was securely blocked from database execution and stored as raw text | **Pass** |
